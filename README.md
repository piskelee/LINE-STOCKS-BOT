# 📈 KD LINE BOT（多股票監控）

一個使用 **GitHub Actions 自動執行** 的股票技術分析監控系統。

系統會在每日固定時間自動抓取股票資料，計算 KD 指標、均線趨勢，並透過 **LINE Flex Message 卡片** 推播選股結果。

---

# 🚀 功能

- 📊 KD 指標計算（9,3）
- 🔵🟢🟡🔴 KD 市場狀態判斷
- 🟢 KD 黃金交叉提醒
- 🔴 KD 死亡交叉提醒
- 📈 MA20 / MA60 趨勢判斷
- 🟢 買進訊號判斷
- ⭐ 股票評分排序
- 📱 LINE Flex Message 表格推播
- 📂 支援 list.txt 多股票監控
- ☁️ GitHub Actions 自動執行

---

# 📊 KD 市場狀態規則

| K值 | 狀態 | 說明 |
|-----|------|------|
| K ≤ 20 | 🔵 極度超跌 | 可能反彈區 |
| 20 < K ≤ 35 | 🟢 低檔 | 重點觀察區 |
| 35 < K ≤ 80 | 🟡 中性 | 盤整觀察 |
| K > 80 | 🔴 過熱 | 注意回檔 |

---

# 📈 MA 趨勢判斷

使用：

- MA20：短期趨勢
- MA60：中期趨勢


| 條件 | 趨勢 |
|---|---|
| MA20 > MA60 | 📈 多頭 |
| MA20 < MA60 | 📉 空頭 |

---

# 🟢 買進訊號規則

綜合：

- KD 狀態
- MA 趨勢
- KD 交叉


| 條件 | 訊號 |
|---|---|
| KD低檔 + 多頭 + 黃金交叉 | 🟢 強力買進 |
| KD低檔 + 多頭 | 🟡 觀察買進 |
| KD低檔 + 空頭 | ⚪ 等待 |
| KD過熱 | 🔴 避免追高 |

---

# ⭐ 評分機制

總分 10 分：

| 條件 | 分數 |
|-|-:|
| KD 極度超跌 | +3 |
| KD 低檔 | +2 |
| MA20 > MA60 多頭 | +2 |
| KD 黃金交叉 | +3 |

分數越高代表符合策略條件越多。
